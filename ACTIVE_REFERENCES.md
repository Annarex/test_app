# Реально используемые справочники в приложении

## ✅ Активно используются в расчетах и логике

### Основные справочники (обязательные для расчетов):
1. **Коды доходов** (`v_budgetclastypeinc_merged`)
   - Используется в: `CalculationController`, `Form0503317`, `DatabaseManager.calculate_sums_from_values()`
   - Назначение: Определение уровней кодов доходов для расчетов и агрегации
   - Статус: **КРИТИЧЕСКИ ВАЖЕН** - без него невозможны расчеты доходов
   - Загрузка: из VIEW с фильтром по дате (`get_filtered_view`, `load_income_reference_df()`), дата из конфига/метаданных ревизии

2. **Коды источников** (`source_reference_records`)
   - Используется в: `CalculationController`, `Form0503317`, `DatabaseManager.calculate_sums_from_values()`
   - Назначение: Определение уровней кодов источников финансирования для расчетов
   - Статус: **КРИТИЧЕСКИ ВАЖЕН** - без него невозможны расчеты источников
   - Загрузка: через `ReferenceController.load_reference_file()` из Excel

### Справочники конфигурации (используются для работы с проектами):
3. **Годы** (`ref_years`)
   - Используется в: `ProjectController`, `DatabaseManager`
   - Назначение: Выбор года для проекта
   - Статус: **ИСПОЛЬЗУЕТСЯ**

4. **Муниципальные образования** (`ref_municipalities`)
   - Используется в: `ProjectController`, `DatabaseManager`
   - Назначение: Выбор муниципального образования для проекта
   - Статус: **ИСПОЛЬЗУЕТСЯ**

5. **Типы форм** (`ref_form_types`)
   - Используется в: `ProjectController`, `DatabaseManager`
   - Назначение: Выбор типа формы (0503317 и др.)
   - Статус: **ИСПОЛЬЗУЕТСЯ**

6. **Периоды** (`ref_periods`)
   - Используется в: `ProjectController`, `DatabaseManager`
   - Назначение: Выбор периода для проекта
   - Статус: **ИСПОЛЬЗУЕТСЯ**

## 📊 Онлайн справочники (только просмотр)

Все онлайн справочники загружаются из API бюджетной системы через `services.budget_references_service.BudgetReferencesService` и используются только для просмотра данных:

### Базовые таблицы:
- `oktmo` - Общероссийский классификатор территорий муниципальных образований
- `budgetclastypeinc` - Классификаторы доходов бюджета ФУ (+ `npa`)
- `budgetclassubtypincmo` - Классификаторы доходов бюджета МО (+ `npa`)
- `budgetclasgabs` - Администраторы бюджета ФУ (+ `npa`)
- `budgetclasgabsmo` - Администраторы бюджета МО (+ `npa`)
- `budgetclasgrbs` - Распорядители бюджета ФУ (+ `npa`)
- `budgetclasgrbsmo` - Распорядители бюджета МО (+ `npa`)
- `budgetclascosts` - Классификаторы расходов бюджета ФУ (+ `npa`)
- `budgetclascostsmo` - Классификаторы расходов бюджета МО (+ `npa`)
- `budgetclasgaiffb` - Источники финансирования дефицита ФУ (+ `npa`)
- `budgetclasgaifmo` - Источники финансирования дефицита МО (+ `npa`)
- `budgetclassources` - Классификаторы источников финансирования ФУ (+ `npa`)
- `budgetclassourcesmo` - Классификаторы источников финансирования МО (+ `npa`)
- `budgetclaskvr` - Коды видов расходов (КВР) (+ `npa`)
- `budgetclasrzpr` - Коды разделов и подразделов (РЗПР) (+ `npa`)
- `budgetclaskcsr` - Коды целевых статей расходов ФУ (КЦСР) (+ `npa`)
- `budgetclaskcsrmo` - Коды целевых статей расходов МО (КЦСР) (+ `npa`)

### Объединенные представления (VIEW):
Объединяют данные ФУ и МО для удобного просмотра:
- `v_budgetclastypeinc_merged` - Классификаторы доходов (объединенные)
- `v_budgetclascosts_merged` - Классификаторы расходов (объединенные)
- `v_budgetclasgrbs_merged` - Распорядители бюджета (объединенные)
- `v_budgetclasgabs_merged` - Администраторы бюджета (объединенные)
- `v_budgetclasgaif_merged` - Источники финансирования дефицита (объединенные)
- `v_budgetclassources_merged` - Классификаторы источников финансирования (объединенные)
- `v_budgetclaskcsr_merged` - Коды целевых статей расходов (объединенные)

**Примечание:** Справочники с `has_npa: True` показывают данные из связанной таблицы `npa` (нормативно-правовые акты).
